# BidLens Realistic Judge Demo Playbook

All vendors/prices/clauses are fictional.

## PRIMARY WOW — CRM
Base: 1,000 users, 3 years.
Stress: 8,000 users, 3 years.
Ask: "Why did the winner change?"
Show the evidence behind the change.

## HIDDEN TCO — Data Platform
Ask: "Which bid is cheapest to own, not cheapest to buy?"
Expose query overage, support requirement, egress and minimum commitment.

## HARD GATE — Cybersecurity
Ask: "Would you award to the cheapest vendor if it fails a mandatory requirement?"
The system should distinguish a hard gate from a weighted score.

## MISSING INFORMATION — Payroll
Ask: "What would you ask the vendor before award?"
Focus on renewal cap, filing penalty coverage and API export ambiguity.

## NEGOTIATION — Contact Center
Ask: "Who wins, and what three things should I negotiate?"
Use the negotiation clues as leverage.

## 4-MINUTE SHOW
0:00 messy proposals
0:20 upload
1:00 recommendation
1:30 hidden risk + evidence
2:00 scenario simulator
2:15 change 1,000 -> 8,000
2:30 winner flips / explain why
3:10 negotiation question
3:40 architecture
4:00 close: "Other tools compare bids. BidLens stress-tests the decision."

## Judge questions
"Isn't this an LLM wrapper?"
-> "AI understands proposal language; deterministic code calculates TCO and scenarios."

"What if AI is wrong?"
-> "Material facts are evidence-backed, missing information is explicit, confidence is shown, and humans approve the award."

"What is novel?"
-> "Evidence-grounded proposal intelligence combined with deterministic TCO and live counterfactual award simulation."
